# Freelance Tracker

A React app to track freelance clients, projects, and payment status across any platform (Upwork, Fiverr, direct clients, etc).

## Features
- Add, edit, and delete clients
- Track payment status
- Dashboard summary (total, paid, pending)
- Live USD to NPR exchange rate
- Follow-up reminders for clients you haven't heard back from
- Data persists using localStorage

## Built With
- React (Vite)
- React Router
- Context API + useReducer
- Custom Hooks

## What I Learned
Built this project from scratch to learn React fundamentals — components, hooks, state management, routing, and API integration — while solving a real problem I have as a freelancer.
